1. Large Signal Amplifiers

A Large Signal Amplifier (also known as a Power Amplifier) is a circuit designed to handle high levels of voltage and current to deliver maximum power to a load, such as a loudspeaker. Unlike small signal amplifiers, which focus on preserving the shape of a tiny voltage, large signal amplifiers operate over the entire length of the load line.

2. Classification by Conduction Angle

Amplifiers are classified based on how much of the input cycle (out of 360 degrees) the transistor remains active.

Figure 2.1: Comparison of output waveforms based on conduction angle
Class Conduction Angle Q-Point Position Efficiency
Class A 360 Degrees Center of Load Line 25% to 50%
Class B 180 Degrees At Cutoff Point 78.5%
Class AB 180 to 360 Degrees Just above Cutoff 50% to 78%
Class C Less than 180 Below Cutoff Above 80%
3. Class A Amplifiers in Detail

In Class A operation, the collector current flows at all times during the full cycle of the signal. This results in minimum distortion but low efficiency because the transistor is "ON" even when there is no input signal.

Figure 3.1: Load line analysis for Class A operation

Efficiency Formula:
Efficiency = (AC Output Power / DC Input Power) x 100
