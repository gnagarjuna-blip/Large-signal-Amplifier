What are Power Amplifiers?

Definition (From: power amp int.jpeg)

  • It is an amplifier with high output power
  • It is mainly used to deliver a large amount of power to a load.
  • The output may be in the form of large voltage or large current.
  • It is also called as large signal amplifier.

Features of Power Amplifier (From: features of pa.png)

  • → The power handling capacity is large
  • → Low output resistance
  • → Impedance matching is required
  • → Power transistors with heat sink are used
  • → Distortion analysis is important

Class A Amplifier

Key Characteristics (From: class a power.png)

360° conduction - In a class A amplifier, the transistor is 'on' for the full cycle (360°) of the AC input signal.

The Q-point is always positioned at the midpoint of the load line.

Fig 1: Class A Operation - Full 360° Conduction
  • Efficiency: Maximum 25% (Direct Coupled) / 50% (Transformer Coupled)
  • Distortion: Lowest among all classes
  • Biasing: Always biased in active region
  • Applications: High-fidelity audio pre-amplifiers, where low distortion is critical

Class B Amplifier

The transistor conducts for only 180° (half cycle). Usually used in a Push-Pull configuration where one transistor handles the positive half and the other handles the negative.

Crossover Distortion

Crossover Distortion: Occurs because transistors don't turn on until the signal reaches ~0.7V. There's a "dead zone" where neither transistor conducts during the zero-crossing transition.

  • Efficiency: Maximum 78.5% (theoretical)
  • Distortion: Higher than Class A, especially crossover distortion
  • Applications: Audio power amplifiers, RF power amplifiers

Class AB Amplifier

A compromise between Class A and Class B. It conducts for slightly more than 180° to eliminate crossover distortion.

Fig 3: Class AB - Eliminates Crossover Distortion

Why Class AB?

Class AB amplifiers are biased so that both transistors are conducting a small amount of current even when there's no input signal. This eliminates the "dead zone" found in Class B amplifiers, thus removing crossover distortion while maintaining good efficiency.

  • Efficiency: Between 50% and 78.5%
  • Distortion: Very low, no crossover distortion
  • Applications: Most common in high-quality audio power amplifiers, car audio systems, home theater systems

Class C Amplifier

The transistor conducts for less than 180°. It produces high distortion but very high efficiency (over 80%).

LC Tank Circuit

Note: Used almost exclusively in Radio Frequency (RF) transmitters where the "Tank Circuit" (LC resonant circuit) filters out the distortion and reconstructs the sine wave.

Class C with LC Tank Circuit: +Vcc │ │ ┌──┴──┐ │ │ Transistor └──┬──┘ │ ┌──┴──┐ │ L │┐ │ C │┼─ Tank Circuit (resonant) └─────┘│ │ ─┴─→ RF Output GND
  • Efficiency: Highest - up to 90%
  • Distortion: Very high (cannot be used for audio)
  • Applications: RF transmitters, RF power amplifiers, frequency multipliers
  • Biasing: Reverse biased or zero biased
