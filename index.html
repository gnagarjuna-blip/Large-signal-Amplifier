Power amplifiers handle large signals and aim for maximum power transfer to the load.

  • Impedance Matching: Vital for efficiency. The output resistance must match the load resistance.

The transistor conducts for the full cycle ($360^{\circ}$).

ηmax (Direct Coupled) = 25%

Since the transistor is always ON, it dissipates significant heat even when no signal is present.

The position of the Quiescent (Q) point on the DC/AC load line determines the Amplifier Class.

ClassQ-Point Location
Class ACenter of Load Line
Class BAt Cut-off Point (X-axis)
Class CBelow Cut-off Point
